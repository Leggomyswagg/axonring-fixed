# Exact Technical Specs (Publish Publicly)

## Hardware

| Spec                    | Detail                                      |
|-------------------------|---------------------------------------------|
| Chip                    | NTAG (ISO 14443 Type A)                     |
| Power                   | Passive — draws energy only when read by a phone. Never needs charging. |
| Material                | Sealed ceramic composite, hypoallergenic    |
| Finish options          | Matte black (Executive) · Polished with gold accent (Prestige) |
| Water resistance        | Suitable for showers, swimming, and daily wear. No ports or battery to fail. |
| Weight                  | Approximately 3–6 g depending on size       |
| Thickness               | Designed for everyday comfort (jewelry profile) |
| Sizes                   | US 6 through 13                             |

## Compatibility

- iPhone 7 and newer (NFC reading)
- Android phones with NFC enabled
- No app required on the receiving phone for business card or link
- Writing/setup uses free apps: NFC Tools (iOS & Android) or similar

## Functional Limits (Honest)

- Memory is limited to what a standard NTAG chip holds (contact card, URL, or short automation payload)
- Access control works only if the building system supports and enrolls third-party NFC credentials
- Smart-home control works only through the user’s existing phone automation apps

## What Is Not Included

- No sensors (PPG, temperature, accelerometer, etc.)
- No battery or charging case
- No display or buttons
- No secure element for terminal payments
